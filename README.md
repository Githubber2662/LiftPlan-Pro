# LiftPlan Pro

A standalone elevator engineering and planning web application built with HTML5, CSS3 and vanilla JavaScript.

## Run
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox or Safari).
3. No build step, package manager, server or external JavaScript dependency is required.

## Features
- EN 81, IS 17900 and ASME A17.1 / CSA B44 planning profiles
- Building and elevator group inputs
- Simplified traffic / RTT / interval / five-minute handling estimates
- Car and shaft geometry screening with SVG plan illustration
- Indicative traction power and energy estimates
- Quick calculators and custom lifting-power calculator
- Standards review checklists with completion tracking
- Browser localStorage save, JSON import/export, CSV summary and print-to-PDF

## Important engineering limitation
This software is a preliminary planning aid. It does not contain a verified clause-by-clause implementation of EN 81, IS 17900 or ASME requirements and must not be used as evidence of compliance or as a substitute for qualified engineering design. Verify the adopted editions, amendments, local authority requirements, equipment manufacturer's drawings and all safety-critical calculations independently.

The traffic, shaft allowance, motor power and energy models are deliberately simplified estimates. The shaft drawing is indicative only and is not a construction drawing.
